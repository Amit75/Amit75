# Aarulya Store brand asset manifest

## Ownership statement

The Aarulya Store mark in this repository is a first-party geometric source asset created for Aarulya Store. It is not imported from another app, marketplace, icon pack or third-party brand.

## Canonical source assets

- Web/vector source: `assets/aarulya-store-mark.svg`
- Android vector mark: `android-store/app/src/main/res/drawable/ic_aarulya_mark.xml`
- Android monochrome mark: `android-store/app/src/main/res/drawable/ic_aarulya_monochrome.xml`
- Adaptive launcher icons: `android-store/app/src/main/res/mipmap-anydpi-v26/` and `mipmap-anydpi-v33/`
- Baseline launcher resources: `android-store/app/src/main/res/mipmap-anydpi/`

## Visual construction

- Base: navy circular field
- Primary symbol: original geometric letter A
- Primary accent: Aarulya gold
- Functional accent: Aarulya cyan crossbar
- Secondary highlight: small white trust point

## Canonical palette

- Navy: `#0F1E2E`
- Ink: `#0B0F1A`
- Blue: `#1E6BFF`
- Cyan: `#00D4E0`
- Gold: `#F5C06A`
- Surface: `#F8FAFC`
- White: `#FFFFFF`

## Usage rules

- Do not replace the canonical mark with a copied store, play-button or third-party marketplace icon.
- Do not stretch, rotate or recolor the mark outside the approved palette without a reviewed brand revision.
- App launcher, Android splash, account gate, Store header and website favicon must use the canonical source mark.
- The monochrome resource is used only by Android themed icons.
- Any future raster export must be generated from the canonical vector and recorded with its SHA-256 in the release evidence pack.

## Evidence boundary

This manifest records repository-side source ownership and consistency. Final release evidence still requires exact-file digests, source commit, reviewer identity, trademark review, signed approval and transparency inclusion. No legal registration or production release is claimed by this document alone.
